# Test Cases для страницы сборника игр по разным жанрам

**Входные условия**:
- Main page: https://makarovartem.github.io/frontend-avito-tech-test-assignment/

## 1. Тест-кейс: Открытие карточки игры

**Шаги:**
1. Открыть Main page.
2. Дождаться загрузки карточек игр.
3. Кликнуть по первой карточке игры.
4. Дождаться перехода на страницу деталей игры (ожидается, что URL содержит слово "game").

**Ожидаемый результат:**
- Страница деталей игры открывается, URL содержит "game".

## 2. Тест-кейс: Отображение разного количества карточек игр на странице поиска

**Шаги:**
1. Открыть Main page.
2. Дождаться загрузки блока пагинации и зафиксировать значение последней страницы (например, значение последнего элемента в пагинации).
3. Выбрать в фильтре "Filter by platform" опцию "Browser".
4. Дождаться обновления блока пагинации.
5. Получить новое значение последней страницы пагинации.

**Ожидаемый результат:**
- Значение последней страницы после применения фильтра должно быть меньше, чем до его применения, то есть количество страниц должно уменьшиться.

## 3. Переход по страницам результата поиска с помощью пагинации

**Шаги:**
1. Открыть Main page.
2. Выбрать в фильтре "Filter by platform" опцию "Browser".
3. Получить название игры из первой карточки на первой странице.
4. Перейти на вторую страницу пагинации, кликнув по элементу с номером "2".
5. Получить название игры из первой карточки на второй странице.

**Ожидаемый результат:**
- Названия игры на первой и второй страницах должны различаться, что свидетельствует о корректном переходе на вторую страницу.
