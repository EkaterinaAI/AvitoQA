# Avito QA Задание 2.2

## Описание

Проект содержит автоматизированные Е2E-тесты для критических пользовательских сценариев на странице сборника игр по разным жанрам. Тесты проверяют:
- Открытие карточки игры (переход на страницу деталей игры);
- Отображение разного количества карточек игр на странице поиска;
- Переход по страницам результата поиска с помощью пагинации.

## Требования
- Java 8 или выше
- Maven
- Google Chrome
- Selenium WebDriver, JUnit 5, WebDriverManager (автоматическая настройка ChromeDriver)

## Структура проекта
- **src/test/java/e2e** – тестовый класс
- **src/test/java/pages** – классы Page Object с использованием Page Factory
- **TESTCASES-Task2.md** – описание тест-кейсов
- **BUGS-Task2.md** – баг-репорты

## Запуск тестов
1. Клонировать репозиторий.
2. Перейти в корневую папку проекта.
3. Выполнить команду: mvn test.
4. Результаты тестов выводятся в консоли.

## Тест-кейсы
- **Открытие карточки игры:** клик по первой карточке игры ведёт на страницу деталей, проверяется изменение URL.
- **Отображение разного количества карточек:** проверяется изменение количества страниц пагинации после применения фильтра «Browser».
- **Пагинация:** проверяется переход на вторую страницу (на основе изменения названия игры).

## Баг-репорты
Баги оформляются в файле **BUGS-Task2.md** с указанием входных условий, шагов воспроизведения, ожидаемого и фактического результата.

## Примечания
- Решение реализовано на Java с использованием Selenium, JUnit 5 и паттерна Page Object.
- Все тестовые сценарии используют явные ожидания для повышения стабильности тестов.
